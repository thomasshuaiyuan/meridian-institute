## SCHEDULE — ASSIGNED INTELLECTUAL PROPERTY

### IP Asset 1: Barrier Metric Framework
A genome-level quantitative method for computing the reversion probability of live-attenuated viral vaccines (LAVs). The framework models attenuation as a function of the cumulative mutational distance between attenuated and wild-type coding sequences, incorporating codon-level selection pressure and evolutionary fitness landscapes to produce a continuous scalar metric ("barrier score") predictive of the probability and speed of phenotypic reversion. Includes: theoretical model specification, mathematical formulation, and all associated documentation.

### IP Asset 2: VC2 Methodology (Viral Codon Volatility Coefficient — Version 2)
A methodology for computing a codon-level volatility coefficient that quantifies how readily each position in a viral genome can revert under natural selection. VC2 extends prior codon volatility concepts by incorporating multi-step reversion trajectories and phylogenetically-informed substitution rates. Includes: methodology specification, algorithmic description, and all associated documentation.

### IP Asset 3: Reversion Probability Pipeline
A computational pipeline implementing the barrier metric and VC2 calculations, including: k-mer walk algorithm for enumerating reversion trajectories through sequence space; scoring functions integrating substitution rate matrices and codon fitness estimates; output format specifications; validation framework against historical attenuation/reversion data. Includes: all source code, scripts, configuration files, and documentation created by Thomas Yuan in connection with this pipeline.

### IP Asset 4: Related Know-How and Documentation
All laboratory notebooks (electronic and physical), research notes, presentations, preprints, and unpublished manuscripts authored or co-authored by Thomas Yuan that describe, implement, or rely on IP Assets 1–3.
